🎮 ASCII Rock Paper Scissors (Tkinter GUI)

A simple Rock Paper Scissors game built with Python and Tkinter GUI, featuring ASCII art styled buttons.

🚀 Features

GUI built with Tkinter

ASCII art buttons (Rock, Paper, Scissors)

Random computer selection

Score tracking system

Clean and minimal design

🖥️ Preview

The game uses ASCII art like:

    _______
---'   ____)
      (_____)
      (_____)
      (____)
---.__(___)


Buttons are styled using a monospace font to preserve formatting.

📦 Requirements

Python 3.x

Tkinter (comes pre-installed with Python)

If you're using Anaconda:

conda create -n rps python=3.11
conda activate rps

▶️ How to Run

Navigate to the project folder:

cd Rock_Paper_Scissorts/Rock_Paper_sc


Run the game:

python main.py


If needed:

/opt/anaconda3/bin/python3 main.py

🧠 Game Rules

Rock beats Scissors

Scissors beats Paper

Paper beats Rock

Same choices result in a draw
